# Windows Privilege Escalation Labs

Use intentionally vulnerable or self-owned Windows lab systems.

## Suggested Lab Categories

- Weak service permissions
- Unquoted service paths
- Writable service binaries/directories
- Scheduled task weaknesses
- Registry permission issues
- DLL search-order issues
- Credential exposure
- Token privilege scenarios
- UAC research
- Kernel exploit validation

## Lab Record

For each lab record:

- Windows version/build
- Initial user/context
- Enumeration performed
- Candidate finding
- Manual validation
- Result
- Evidence
- Cleanup
- Lesson learned
